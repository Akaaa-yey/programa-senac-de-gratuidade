Dúvidas sobre Renda e Documentos

Qual é o limite de renda para participar?

A renda per capita familiar não pode ultrapassar 2 salários mínimos federais.

Como a IA analisa meus documento?

O sistema extrai os dados via OCR. Caso a imagem esteja embaçada ou ilegível, o documento será direcionado para análise humana pela equipe do SENAC.
